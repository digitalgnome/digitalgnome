### 🛠️ Things I've made

| Project | What it does | Built with |
|---|---|---|
| 🎛️ **[keydial-mini-linux](https://github.com/digitalgnome/keydial-mini-linux)** | Linux driver and settings app for the Huion Keydial Mini, with radial menus for apps and profiles, over USB or Bluetooth | Python · PySide6 · KDE |
| 🦖 **[dimcardtool-linux](https://github.com/digitalgnome/dimcardtool-linux)** | Back up, restore and unlock Digimon Vital Bracelet DIM cards on Linux. A port of Mr. Blinky's Windows tool | Python · libusb |
| 🎮 **[override](https://github.com/digitalgnome/override)** | Decky Loader plugin: download cheat packs and change in-game values from the Steam Deck's Quick Access menu | TypeScript · Python |
| 💾 **[compatdata-to-sd](https://github.com/digitalgnome/compatdata-to-sd)** | Free up Steam Deck storage by moving Proton prefixes to the SD card | Python |
| ⚔️ **[ff-party-card](https://github.com/digitalgnome/ff-party-card)** | A Final Fantasy-style party menu for Home Assistant: phone battery as HP, status effects and all | JavaScript · HACS |
